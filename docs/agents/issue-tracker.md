# Issue tracker: GitHub

Issues and specs for this repo live as GitHub issues. Use the `gh` CLI for all operations.

## Conventions

- Create, read, comment on, label, and close issues through `gh issue`.
- Infer the repository from the configured Git remote.
- Pull requests are not treated as feature requests by triage.
- When a skill says “publish to the issue tracker”, create a GitHub issue.
- When a skill says “fetch the relevant ticket”, retrieve that GitHub issue with its comments and labels.
- Wayfinder maps and their child tickets are represented as linked GitHub issues.
- Use native GitHub sub-issues and dependencies when available, with issue-body links as fallback.
